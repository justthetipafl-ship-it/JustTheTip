Record a bet

Saves to data/results.json in the JustTheTip repo. The site reads that file for the results dashboard.
The dashboard shows units only, never dollars. A $50 stake at a $25 unit is 2u. This converts this entry as you save it — it never rescales bets already logged.
Legs optional
Add the legs and the bet tracks live on the site while the game is on, then settles itself from the game logs. Leave it empty and the bet still publishes — it just has to be settled by hand.
Not yet saved
Stored only in this browser (localStorage), never sent anywhere except github.com. Use a fine-grained personal access token limited to the JustTheTip repo with Contents: read and write — nothing else. If the phone is lost, revoke it on GitHub and the token is dead.
